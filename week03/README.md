# 3주차 - 셸 스크립팅

## 1. 실습 환경
- Ubuntu 및 Python3
- Ollama 설치 및 Qwen 모델 다운로드

## 2. AI 웹 서비스 실습
- Qwen3:0.6b 모델 실행
- chat.py를 이용한 웹 채팅 서비스 실행
- localhost:8000 접속 및 응답 확인

## 3. 셸 스크립트 실습
- start.sh 작성 및 실행 권한 설정
- Shebang 및 실행 경로 설정
- 환경 변수 MODEL, WEB_PORT 설정
- 웹 서버 포트를 8000에서 8080으로 변경

## 4. 조건문 실습
- command -v를 이용한 Python 설치 여부 확인
- if 조건문으로 오류 상황 처리

## 5. 실습 결과
- 로컬 AI 채팅 서비스 실행
- 셸 스크립트를 이용한 실행 자동화
- 환경 변수 및 조건문 활용
